## 这个博客是怎么搭的

- 用 [Astro](https://astro.build/) 把 Markdown 文章生成静态网页；
- 源码放在 GitHub 仓库里；
- Cloudflare Pages 监听仓库，每次 `git push` 后自动构建并发布；
- 域名托管在 Cloudflare，HTTPS 证书自动签发、自动续期。

整个流程不需要自己维护服务器，也不用花钱。
